# SkateBIRD Takeover

**Quake** × SkateBIRD · visual · idea by the team

Bring SkateBIRD into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I put SkateBIRD into Quake: every grunt is now a shred bird on a skateboard that kickflips at you, and the combo trick text is ridiculous.

## Install

Copy the mod folder into your Quake (Ironwail or LibreQuake) directory and start the game with -game <folder name>. Load a map such as lq_e0m1 and watch the skateboarding birds attack.
